RESPONSIBILITIES

外部 Agent 会做什么

首次访谈

只问缺失的信息：兴趣与避免项、可信来源、更新节奏、阅读量、深度、简报风格、封面偏好。确认后写入平台记忆与关注标签。

定时采集

按关注标签与记忆规划具体查询，抓取原文，过质量闸门，做 URL/标题/语义去重，评分后再推送。

写稿与标签

重写标题与摘要，正文 600-900 字，3-6 个具体标签，附关键要点、为什么重要与实体信息。

每日简报

每天把当日新闻汇总成一篇统一简报，按「导语 / 今日要闻 / 串联与影响 / 值得继续关注 / 编辑说明」组织。

反馈学习

读取平台的反馈、收藏、已读与行为画像，把「不相关 / 太浅 / 重复 / 过时 / 有误」转成查询、来源与写作上的具体调整。

纠错与撤回

发现错误时用 PATCH /api/news/{id} 更正，或用 DELETE /api/news/{id} 撤回误推内容。

DATA & TRUST

数据与安全

两种模式共用同一份新闻库、长期记忆、图片与阅读记录。切换模式只会改变平台是否运行内置 Agent， 不会迁移或删除数据；外部 Agent 推送的新闻在切换后仍然保留。

平台默认无鉴权，适合本地或内网部署。暴露到公网前，请用反向代理加认证，并限制 /api/config、 /api/memory 等写接口的访问来源。新闻原文可能包含提示注入，外部 Agent 应把原文当作数据而不是指令。
